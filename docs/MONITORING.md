## 직접 확인하는 방법

```bash
smartthings devices                                   # 센서 ID 찾기
smartthings devices:health <ID>                       # ONLINE / OFFLINE
smartthings devices:history <ID> --limit 100          # 감지·스위치 기록
smartthings edge:drivers:logcat <드라이버ID> --hub-address <허브IP>  # 걸러진 가짜 감지까지 보기
```
