## NEO Motion Sensor (3번방)

### 필터 변경 전 (예전 필터, 1주일치 기록 분석)

- 빈 방에서 **118분(7080초) 간격** 가짜 감지가 이어짐. 사람이 움직여도 이 시계는 리셋되지 않음, 몇 바퀴마다 약 1초씩 밀림.
- 예전 필터(모든 감지 기준 118분 배수)는 하루의 3~6%가 함정이라 **진짜 감지 7건을 버렸음** → 10/27 아침 "센서가 동작을 안 해서 스위치를 손으로 켠" 일의 원인.
- 새 방식으로 같은 기록을 다시 돌려 봄(JS·Lua 둘 다): 가짜 감지 25건 중 23건 거름, 나머지 2건은 사람이 움직이던 시간. 진짜 감지 7건 모두 통과.

## 직접 확인하는 방법

```bash
smartthings devices                                   # 센서 ID 찾기
smartthings devices:health <ID>                       # ONLINE / OFFLINE
smartthings devices:history <ID> --limit 100          # 감지·스위치 기록
smartthings edge:drivers:logcat <드라이버ID> --hub-address <허브IP>  # 걸러진 가짜 감지까지 보기
```
