### 남은 위험 (NEO)

- 빈 방에서 가짜 감지와 같은 3초 안에 들어오면 최대 32초 늦게 켜짐 (반년에 한 번꼴 추정). 2초 안에 나가면 못 켬.
- 센서 시계가 평소보다 더 밀리면(+2초 이상) 가짜 감지가 새어 빈 방에 불이 켜질 수 있음 (사람 놓치는 쪽 아님).
- 가만히 있으면 PIR은 못 봄 → 루틴의 "움직임 없음 1분 뒤 끄기" 때문에 꺼질 수 있음.

### 확인 방법 메모

- **걸러진 감지는 기록에 흔적이 없습니다.** SmartThings는 같은 값의 반복("움직임 없음" → "움직임 없음")을 기록하지 않습니다. 허브 로그(`smartthings edge:drivers:logcat`)에서 `NEO: phantom 118-minute motion report ignored` / `NEO: still occupied after an ignored report` 로그로 확인하세요.
- 사람을 놓쳤는지는 **"센서 감지 없이 스위치가 켜짐"**(손으로 켬)으로 봅니다. `devices:history`로 스위치 켜짐 직전 60초 안에 감지가 있었는지 비교하세요.
- 회사 노트북의 감시 스크립트(`%TEMP%\neo_watch\`)는 저장소에 없습니다.

## 대안 (보류)

- 남는 AOYAN을 3번방에 두고, 가짜 감지 3초 창에서만 AOYAN 감지 여부로 즉시 판정 → 지연 0. 사용자가 3번방 추가 설치를 원하지 않아 보류.
- NEO가 Matter OccupancySensing의 감지 판단 기준/유지 시간 설정을 지원하는지 미확인 (앱에 안 보이는 건 드라이버가 안 보여 주기 때문일 수 있음).

## AOYAN 센서가 죽던 원인 (추정, 미확인)

- 센서가 **주방 간접등(Zigbee 전구)을 중간 연결 기기로 사용**했음. 일부 전구는 배터리 센서를 연결 목록에서 빼 버림.
- 허브의 **Zigbee 보안 모드가 켜져 있어**(unsecure rejoin 꺼짐) 싸구려 Tuya 기기가 다시 붙지 못할 수 있음.
